《云端枕边书 (Cloud Lullaby)》是一款专为留守儿童与外地务工父母设计的**“异步亲子情感共创”平台**。

本项目依托视觉大模型 (VLM) 与大语言模型 (LLM)，将儿童随心所欲的涂鸦与童言童语智能转化为童话大纲，并让远在千里之外的父母利用下班后的碎片化时间，进行一键快捷确认或短语音互动。系统最终融合双端输入，生成精美的多模态绘本并利用父母克隆音色（Voice Cloning）进行睡前伴读，旨在以科技力量跨越物理阻隔，重构亲子情感连接并提供早期的心理辅助守护。
